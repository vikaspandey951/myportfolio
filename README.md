# Vikas Pandey | AI/ML Engineer Portfolio

A space-themed portfolio for Vikas Pandey, an AI/ML Engineer focused on healthcare AI, NLP, OCR, computer vision, and FastAPI services.

## Highlights

- AI/ML skills: Python, Machine Learning, Deep Learning, NLP, Computer Vision, OCR, PyTorch, TensorFlow, and Hugging Face
- Backend skills: FastAPI, Django, Flask, REST APIs, MongoDB, and MySQL
- Experience at DrsMinds TruSignal Pvt Ltd, where Vikas helped build Healthcare AI workflows
- Projects: DocMind AI, AI Health Assistant, NLP Document Summarizer, Django To-Do, Car Rental Management System (C++), and Movie Ticket Booking System (C)
- Certifications section with linked course-completion PDFs (Django, Generative AI, IoT, Software Testing, Cloud Computing, ML, and Data Science)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```
